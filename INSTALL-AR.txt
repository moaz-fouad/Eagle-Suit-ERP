════════════════════════════════════════════════════════════
   EAGLE SUIT  —  دليل التثبيت على الكمبيوتر
════════════════════════════════════════════════════════════

النظام بيشتغل بدون إنترنت وبدون تنصيب برامج.
كل اللي محتاجه: متصفح Google Chrome أو Microsoft Edge (موجود أصلاً مع ويندوز).

────────────────────────────────────────────────────────────
الخطوة ١ — فك الضغط
────────────────────────────────────────────────────────────
١. نزّل ملف  Eagle-Suit.zip
٢. كليك يمين عليه  ←  Extract All  ←  Extract
٣. هيطلعلك فولدر اسمه  eagle_suit

مهم:  حط الفولدر في مكان ثابت مش هتمسحه، مثلاً:
      C:\EagleSuit
      أو على سطح المكتب مباشرة.

⚠ متشغّلش النظام من جوه ملف الـ ZIP — لازم تفك الضغط الأول.

────────────────────────────────────────────────────────────
الخطوة ٢ — التشغيل
────────────────────────────────────────────────────────────
افتح الفولدر واعمل دبل كليك على:

      Eagle-Suit.bat      ←  (الطريقة المفضّلة)

ده بيفتح النظام في نافذة نضيفة من غير شريط عناوين، شكله زي برنامج عادي.

لو مشتغلش لأي سبب، اعمل دبل كليك على:

      index.html          ←  بيفتح في المتصفح العادي

────────────────────────────────────────────────────────────
الخطوة ٣ — تسجيل الدخول
────────────────────────────────────────────────────────────
      مدير  :  admin  /  1234     (كل الشاشات)
      بائع  :  sales  /  1111     (فاتورة البيع فقط)

⚠ غيّر كلمات المرور من:  الإعدادات ← المستخدمين

────────────────────────────────────────────────────────────
الخطوة ٤ — اختصار على سطح المكتب
────────────────────────────────────────────────────────────
١. كليك يمين على  Eagle-Suit.bat
٢. اختار  Send to  ←  Desktop (create shortcut)
٣. تقدر تغيّر اسم الاختصار لـ "Eagle Suit"

عشان تحط له أيقونة اللوجو:
   كليك يمين على الاختصار ← Properties ← Change Icon
   ← Browse ← اختار ملف  assets\favicon.png


════════════════════════════════════════════════════════════
   طريقة أسهل:  ملف واحد بس  (EagleSuit.html)
════════════════════════════════════════════════════════════

لو نزّلت ملف  EagleSuit.html  مش محتاج الفولدر ده خالص.

الملف ده لوحده فيه النظام كله (الأكواد + الصور + اللوجو).
حطه في أي مكان على الجهاز واعمل عليه دبل كليك — يفتح على طول.

  ١. حط الملف في مكان ثابت، مثلاً:   C:\EagleSuit\
  ٢. دبل كليك عليه  ←  يفتح في المتصفح
  ٣. لو مفتحش بكروم: كليك يمين ← Open with ← Google Chrome
  ٤. اعمل اختصار: كليك يمين ← Send to ← Desktop

⚠ متغيّرش اسم الملف ولا مكانه بعد ما تبدأ تشتغل عليه،
   لأن البيانات بتترتبط بمكان الملف.

باقي الخطوات (اختيار مجلد البيانات / الطابعة) زي ما هي تحت.

────────────────────────────────────────────────────────────
الخطوة ٥ — إعداد طابعة الفواتير 80mm
────────────────────────────────────────────────────────────
١. وصّل الطابعة الحرارية وثبّت الدرايفر بتاعها من ويندوز.
٢. اجعلها الطابعة الافتراضية:
      Settings ← Bluetooth & devices ← Printers & scanners
      ← اختار الطابعة ← Set as default
٣. من النظام: اضغط "طباعة" في أي فاتورة
٤. أول مرة بس، في نافذة الطباعة اللي هتفتح:
      • Destination / الوجهة  ←  اختار الطابعة الحرارية
      • Margins / الهوامش      ←  None
      • Scale / المقاس          ←  100
      • شيل علامة  Headers and footers
٥. اضغط Print — والإعدادات دي هتفضل محفوظة للمرات الجاية.

الفاتورة مضبوطة على عرض 72mm (المناسب لرول 80mm).
لو عايز تطبع على A4 أو A5: الإعدادات ← الطباعة ← مقاس الورق.

════════════════════════════════════════════════════════════
   ⭐  أهم خطوة:  اختيار مجلد حفظ البيانات
════════════════════════════════════════════════════════════

اعمل الخطوة دي أول ما تشغّل النظام — مرة واحدة بس.

الافتراضي إن البيانات بتتحفظ جوه كروم في مكان مخفي مش هتشوفه.
عشان تبقى بياناتك في ملف حقيقي على جهازك تقدر تشوفه وتنسخه:

  ١. ادخل بحساب المدير (admin)
  ٢. الإعدادات  ←  النسخ الاحتياطي
  ٣. اضغط  [ اختر مجلد الحفظ ]
  ٤. اعمل مجلد جديد اسمه مثلاً:   C:\EagleSuit\data
  ٥. اضغط  Select Folder
  ٦. كروم هيسألك  "Save changes to this folder?"  ←  اضغط  Edit files

خلاص. من دلوقتي أي حاجة تعملها (بدلة جديدة، عميل، فاتورة)
بتتكتب فوراً في الملف ده:

      C:\EagleSuit\data\eagle_data.json

الملف ده هو قاعدة البيانات كلها. تقدر تنسخه على فلاشة في أي وقت،
أو تفتحه بالـ Notepad وتشوف كل بياناتك.

وكمان النظام بيعمل نسخة بتاريخ كل يوم لوحده في:

      C:\EagleSuit\data\backups\eagle_2026-07-29.json

────────────────────────────────────────────────────────────
النقطة الخضراء فوق
────────────────────────────────────────────────────────────
جنب الساعة في أعلى الشاشة فيه نقطة صغيرة بتقولك حالة الحفظ:

  🟢 خضرا   =  البيانات بتتحفظ في الملف (كله تمام)
  🟠 برتقاني =  اضغط عليها عشان تسمح لكروم يكتب في المجلد
  ⚫ رمادي   =  الحفظ داخل المتصفح فقط (لسه مختارتش مجلد)

⚠ ملاحظة: كروم أحياناً بيطلب إذن تاني بعد ما تقفل وتفتح البرنامج.
   لو لقيت النقطة برتقاني، اضغط عليها واضغط "Edit files" وخلاص.

────────────────────────────────────────────────────────────
نسخة احتياطية إضافية (مستحسنة)
────────────────────────────────────────────────────────────
كل فترة: الإعدادات ← النسخ الاحتياطي ← تنزيل نسخة (JSON)
وانسخ الملف على فلاشة أو Google Drive.

للاستعادة: الإعدادات ← النسخ الاحتياطي ← اختار الملف

⚠ لو مختارتش مجلد:
   البيانات هتفضل جوه كروم، ولو عملت "Clear browsing data" هتضيع.
   عشان كده مهم جداً تعمل خطوة اختيار المجلد فوق.

════════════════════════════════════════════════════════════
   حلول سريعة لأي مشكلة
════════════════════════════════════════════════════════════

النظام مبيفتحش
   ← كليك يمين على index.html ← Open with ← Google Chrome

الطباعة مش بتفتح
   ← اتأكد إن فيه طابعة متثبتة على الجهاز
   ← جرّب Ctrl + P وانت في الفاتورة

الفاتورة بتطلع بعرض غلط
   ← في نافذة الطباعة: Margins = None و Scale = 100

الشاشة صغيرة أو كبيرة
   ← Ctrl و + للتكبير / Ctrl و − للتصغير / Ctrl و 0 للوضع الطبيعي

البيانات اختفت
   ← الإعدادات ← النسخ الاحتياطي ← استعادة، واختار آخر ملف نسخة
   ← أو افتح مجلد البيانات واختار ملف من جوه فولدر backups

النقطة فوق برتقاني
   ← اضغط عليها ← Edit files  (كروم بيطلب الإذن تاني بعد إعادة التشغيل)

عايز أنقل النظام لجهاز تاني
   ← انسخ ملف eagle_data.json
   ← على الجهاز الجديد: الإعدادات ← النسخ الاحتياطي ← استعادة ← اختار الملف
